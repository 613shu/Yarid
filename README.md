# 🎪 היריד הגדול — The Great Fair

משחק סימולציה בעולם תלת־ממדי של יריד לילה: הסוחרים פותחים דוכנים, ממלאים מלאי, מקשטים וקובעים מחיר —
והלקוחות הווירטואליים מסתובבים ביריד וקונים בדוכנים לפי רשימת קניות, תקציב ואטרקטיביות הדוכן.

פרויקט סיום מקצועי בריאקט.

---

## 🔑 פרטי כניסה לדוגמה

המשתמשים האלה נוצרים אוטומטית ע״י ה־seed של השרת (`npm run db:seed`):

| תפקיד | אימייל | סיסמה |
|---|---|---|
| 👑 מנהל (ADMIN) | `admin@yarid.local` | `Admin1234!` |
| 🧺 סוחר לדוגמה (MERCHANT) | `merchant@yarid.local` | `Merchant1234!` |

אפשר גם להירשם כסוחר חדש בדף ההרשמה — כל סוחר חדש מקבל **1,000 רובלים** מתנת הצטרפות.
פתיחת דוכן עולה 300 רובלים.

> בסביבת ייצור (Render) הפרטים נקבעים במשתני הסביבה `ADMIN_EMAIL` / `ADMIN_PASSWORD` וכו׳.

## ⚛️ על המערכת — צד הריאקט

### טכנולוגיות
- **React 19 + TypeScript + Vite**
- **React Router** — ניתוב, כולל נתיבים מוגנים לפי תפקיד
- **TanStack React Query** — כל הקריאות לשרת, מטמון ורענון אוטומטי
- **Axios** — מופע אחד עם interceptor שמוסיף את ה־JWT לכל בקשה
- **React Hook Form + Yup** — טפסים ואימות
- **React Three Fiber + Drei** — עולם היריד התלת־ממדי
- **Tailwind CSS v4** + ערכת העיצוב `fair3d.css` (עץ, נחושת, זהב פנסים, קלף)

### מבנה התיקיות (`game-fair/src`)
| תיקייה | תפקיד |
|---|---|
| `pages/` | המסכים: בית, התחברות/הרשמה, יריד, פתיחת דוכן, קישוטים, מוצרים, מלאי, ניהול |
| `components/World/` | העולם התלת־ממדי: הכיכר, הדוכנים (Booth), הלקוחות (Shopper), הרקע |
| `components/hud/` | שכבת הממשק מעל העולם: ארנק, כרטיס דוכן, טעינה |
| `components/Models/` | רכיבי תצוגה לישויות: דוכן, לקוח, מוצר, קישוט, סוחר |
| `components/System/` | רכיבים כלליים: כותרת, ניווט, תפריט צד, שדה טופס, קישור |
| `context/` | `AuthContext` (משתמש וטוקן), `WorldContext` (דוכנים ובחירה בעולם), `StallContext` (שלבי פתיחת דוכן) |
| `hooks/` | הוקים לשרת: `useMyQuery`, `useBalance`, `useCustomers`, `useProducts`, `useStock`, `useAddDecoration` |
| `routs/` | הגדרת הנתיבים ו־`ProtectedRouts` |
| `typs/` | טיפוסים וסכמות Yup |

### עקרונות מרכזיים
- **הרשאות לפי תפקיד** — `ProtectedRouts` מקבל רשימת תפקידים (`Guest`, `MERCHANT`, `ADMIN`) ומפנה משתמש שאינו מורשה.
- **מצב שרת ב־React Query** — הארנק מתרענן כל 10 שניות, הלקוחות מתעדכנים מעצמם, ואחרי קנייה (מלאי / קישוט)
  נעשה `invalidateQueries` כדי שהיריד והיתרה יתעדכנו מיד.
- **מצב משותף ב־Context** — הדוכן שנבחר בעולם, הלקוח שנלחץ, ושלבי האשף של פתיחת דוכן.
- **אשף פתיחת דוכן** — שם → מוצר → קישוטים → אישור → מחיר → סיום. הדוכן נוצר בשרת רק בשלב המחיר.
- **הפרדה בין עולם לממשק** — הקנבס התלת־ממדי (`FairWorld`) מכיל רק אובייקטים תלת־ממדיים;
  כרטיסים וכפתורים יושבים ב־`Hud` שמעליו.

### מה אפשר לעשות
- **סוחר:** לפתוח דוכנים, לבחור מוצר, לקנות מלאי, לקשט, לקבוע מחיר, לעקוב אחרי היתרה ולראות אילו לקוחות קנו אצלו.
- **מנהל:** לנהל את הסוחרים ולצפות ביריד.
- **ביריד:** גרירה = סיבוב, גלגלת = זום, לחיצה על דוכן או לקוח = כרטיס פרטים.

## 🚀 הרצה מקומית

צריך שני טרמינלים — שרת ולקוח:

```bash
# טרמינל 1 — השרת (ריפו YaridServer)
npm install
npx prisma migrate deploy
npm run db:seed
npm run dev          # http://localhost:3000

# טרמינל 2 — הלקוח (תיקיית game-fair)
npm install
npm run dev          # http://localhost:5173
```

בקובץ `game-fair/.env.development`:
```
VITE_API_URL=http://localhost:3000/api
```

> שגיאת **Network Error** בהתחברות = השרת לא רץ.
