# עיצוב יריד הלילה — הוראות התקנה

1. העתיקי את הקבצים מתוך התיקייה game-fair לתוך הפרויקט שלך (אותם נתיבים, להחליף קיימים).
2. התקיני את ספריות התלת-ממד:
   npm install three @react-three/fiber@^9 @react-three/drei@^10 @react-three/postprocessing@^3 postprocessing
   npm install -D @types/three
3. npm run dev

## מה השתנה
- כל הלוגיקה, הקריאות לשרת, הקונטקסטים והטפסים נשארו כמו שהם — שונה רק העיצוב.
- מסך היריד (/game) הוא עולם תלת-ממדי: קרוסלה מסתובבת, גלגל ענק, שרשראות אורות, פנסי שמיים, זיקוקים וגחליליות.
  הדוכנים שלך עומדים במעגל סביב הכיכר, והלקוחות הולכים אליהם (לפי targetStallId).
  גרירה = סיבוב, גלגלת = זום, WASD/חיצים = הליכה, Q/E = סיבוב, לחיצה על דוכן = טיסה אליו וכרטיס פרטים.
- בשאר המסכים היריד מסתובב לאט ברקע.
- נוסף מסך פתיחה (HomePage) בכתובת "/" ודף 404 מעוצב.
- כל הצבעים, הגופנים והאנימציות מוגדרים ב-src/styles/fair3d.css.
- תיקיות חדשות: src/components/world (עולם התלת-ממד), src/components/hud (ארנק, כרטיס דוכן, טעינה).
